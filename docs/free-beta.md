# Публикация вне области передачи

Текущим размещением в Render и облачной БД управляет только исходный владелец.
Эта независимая копия предназначена для локальной разработки и не подключена
к его сервисам. Облачные конфигурации и секреты не передаются.

Для запуска используйте корневой `README.md`, а для процесса работы —
`HANDOFF.md` и `AGENTS.md`. Согласованные изменения владелец сможет отдельно
перенести в свой репозиторий для публикации.
