# Бесплатная beta: Render + Neon

1. Создайте Neon Free и пустую beta-базу. Не переносите локальную БД.
2. Через прямую TLS-строку подключения временно задайте DATABASE_URL в локальном терминале и выполните `npm run db:migrate`, затем `npm run db:seed -- 80`. Не сохраняйте пароль в Git. После команд верните локальный DATABASE_URL.
3. Создайте Render Blueprint из приватного репозитория, ветка `codex/free-beta`, файл `render.yaml`. Все сервисы должны оставаться на плане Free.
4. Задайте DATABASE_URL (pooled TLS URL Neon), BETA_AUTH_USER и длинный случайный BETA_AUTH_PASSWORD. Используйте только HTTPS-ссылку Render.
5. Без правильных данных входа страницы, API и ресурсы возвращают 401. При отсутствии настройки пароля Render возвращает 503, а не открывает приложение. Проверьте это в приватном окне перед рассылкой ссылки.
6. Проверьте каталог, радар, матрицу и карточки. Передайте пароль коллегам отдельно от ссылки.

Render засыпает после простоя, первое открытие может быть медленным. Бесплатные лимиты не гарантируют непрерывную доступность. Не включайте платные планы и автоматическое расширение расходов. Общий пароль можно переслать: это защита демонстрации, не корпоративная авторизация. Для отзыва доступа смените пароль и перезапустите сервис.

Локально защита выключена по умолчанию, на Render включается автоматически. На других хостингах обязательно задавайте BETA_AUTH_ENABLED=true. Не добавляйте реальные данные: API показывает содержимое подключённой БД.
