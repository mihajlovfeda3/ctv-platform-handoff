# Решения после ознакомления с материалами

Прочитаны все шесть приложенных PDF, включая схемы и скриншоты, а также локальный HTML-прототип. Исходные материалы и извлечённый текст не включены в репозиторий. Ни одна корпоративная запись не использована как fixture.

Приоритет: пользовательское ТЗ №1 → предметная методология → перспективная архитектура I-SYS × NIS → визуальные ориентиры. Содержимое документов рассматривается как справочная информация, а не как самостоятельное разрешение публиковать материалы, создавать инфраструктуру или расширять объём работ.

| Источник                                           | Применённое решение                                                                                                           |
| -------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| ТЗ №1 из сообщения пользователя                    | Единое Next.js-приложение, PostgreSQL, Drizzle, пять разделов, минимальный сценарный контур; остальные представления отложены |
| «Формулировки в ЦТВ»                               | Разделены сценарий, кейс, поставщик и решение; сценарий допускает отсутствие кейса; оценки не заменяют друг друга             |
| «Справочник цифровых технологий ЦТВ»               | Сохранены три отдельных уровня технологической классификации; реальные элементы справочника не копируются в тестовый набор    |
| «Описание структуры данных и визуализаций для NIS» | Предусмотрены связи между предметными слоями; будущие представления не имитируются в интерфейсе                               |
| «Разработка радара для NIS совместно с I-SYS v2.2» | Общая платформа ЦТВ с расширяемой реляционной моделью; NIS не зашит в код как единственный пользователь                       |
| «I-SYS x NIS»                                      | Карточка сценария как точка просмотра связанных объектов; последующее развитие матриц и портфельных представлений             |
| «ОтКсении27.10»                                    | Узнаваемость радара через голубую подложку, уровни и сине-оранжевую легенду; исходный интерфейс не воспроизводится буквально  |
| `ctv_ux_comparison.html`, вариант A                | Компактные верхние фильтры и широкая рабочая область; полноценный радар и инспектор оставлены следующей итерации              |

Если методологический материал описывает автоматическое вычисление статуса или квадранта, это не становится реализованным правилом: ТЗ №1 запрещает придумывать производные формулы. Если перспективный документ предполагает создание сценария только после кейса, применяется более приоритетное требование о независимом существовании сценария.
