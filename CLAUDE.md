# Продолжение разработки ЦТВ

Перед работой прочитай `AGENTS.md`, затем `HANDOFF.md` и актуальный `README.md`.
Для первого запуска выполни инструкцию восстановления снимка БД, затем проверь
`handoff/manifest.json` и `handoff/VERIFICATION.md`.

Основной запуск — без Docker: Node.js 24 и локальный PostgreSQL 17. Помоги
настроить локальный сервер, отдельную пустую БД `ctv_handoff` и `.env` с
фактическими учётными данными и портом. Затем установи зависимости и восстанови
снимок по README. Docker предлагай только как дополнительный вариант по желанию
разработчика. `setup-handoff.mjs` генерирует Docker-настройки и не создаёт БД
или пользователей в обычном PostgreSQL; для основного запуска он не нужен.

Это рабочая передача существующего продукта. Сохраняй принятые интерфейсы,
ID, оценки, связи, URL-контракты и геометрию куба. Изучай только файлы,
относящиеся к текущей задаче. Не создавай заново реализованные представления.

Работай в этом независимом репозитории и локальной БД. Render, облачная БД и
публикация общей ссылки остаются только у исходного владельца. Не запрашивай
его облачные секреты и не пытайся подключать их к окружению разработчика.

Проверки выбирай по `AGENTS.md`. Не запускай seed для восстановления переданного
набора: для этого есть `node scripts/restore-handoff.mjs`.
