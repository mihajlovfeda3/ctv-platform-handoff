# Первое задание новому ассистенту

Прими разработку существующей платформы ЦТВ. Сначала прочитай корневые
`CLAUDE.md`, `AGENTS.md`, `README.md` и `HANDOFF.md`, затем
`handoff/VERIFICATION.md` и `handoff/manifest.json`.

Проверь текущую ветку и `git status`. Подготовь локальную среду по README,
восстанови переданный снимок в отдельную пустую локальную БД, проверь
контрольные суммы и открытие сайта. Не запускай seed вместо восстановления.

На этом этапе не меняй дизайн, геометрию куба, данные, API и прикладную логику.
Не переделывай реализованные представления. Изучи только необходимые файлы.
Сформулируй коротко, что удалось запустить, какие ограничения данных известны
и что требуется для следующей задачи.

Работай в независимом репозитории разработки. Render, облачная БД и публикация
общей ссылки остаются только у исходного владельца и не входят в эту передачу.
