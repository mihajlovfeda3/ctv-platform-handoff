# Проверка комплекта передачи

Проверено 9 ноября 2026 года в независимом клоне версии
`6fd4fae8c0f98b51cb4117c8d2852c9dbae3d26e`.

## Выполнено

- Зависимости установлены через `npm ci` в пустом каталоге нового клона.
- `setup-handoff.mjs` создаёт локальную `.env`, при повторном запуске сохраняет её побайтно.
- Создана новая отдельная локальная PostgreSQL-БД с суффиксом `_handoff_test`; рабочая БД не использовалась как цель восстановления.
- CLI восстановил 26 таблиц и 80 сценариев. Контрольные суммы всех таблиц совпали со свежим снимком источника, включая оценки, связи, ID и точные временные метки.
- `--verify-only` подтвердил совпадение. Повторное восстановление заполненной БД отклонено с кодом 1; последующая проверка подтвердила сохранность данных.
- Четыре теста восстановления проверяют ограничения адреса/имени БД, восстановление реального набора, отказ от перезаписи и откат при повреждённой контрольной сумме.
- `npm run check`: lint, TypeScript, **125 Vitest-тестов** и production build — успешно.
- На свежем production-сервере нового клона с восстановленной БД: **2 целевых Playwright-теста, 1440×900**, успешно. Проверены бизнес-ландшафт/классы/матрица/карточка, поиск и фильтры, переходы в сценарии, куб, выбор сценария, URL-контекст, переходы между каталогом, радаром и матрицей, фокус и reset.
- Каталоги приложения `src`, `package.json` и `package-lock.json` не изменены относительно baseline; изменены только комплект передачи, инструкции, локальные настройки-примеры и тест восстановления.

## Границы проверки

Фактическая среда — Windows, Node.js 24 и локальный PostgreSQL. Docker Compose
сохранён для удобного запуска PostgreSQL 17, но Docker Desktop здесь не
запускался. Команды для macOS/Linux подготовлены, на этих ОС отдельно не
выполнялись. Локальный прогон 2500 сценариев не запускался: прикладная логика,
схема, фильтры, навигация и генератор не менялись.

CI исходного baseline: https://github.com/mihajlovfeda3/ctv-platform/actions/runs/42592935687
— успешно. CI независимого репозитория проверяется отдельно после push.

Исходная рабочая копия и размещение в Render сохранены. Облачные секреты и
содержимое локальных `.env` не входят в комплект; в истории Git сохранены
предыдущие версии файлов конфигурации, которые сами по себе не дают доступа
к сервисам владельца.
