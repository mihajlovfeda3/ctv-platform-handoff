# Стабильная база ЦТВ

Проверенный SHA приложения: `de49b1c5557d6b229aa9d017c186fb40bb0f23d5` (`codex/free-beta`). Ветка `main` включает этот коммит и данную запись. Новые функциональные ветки создаются от `main`.

Включены «Обзор» и глобальная навигация, каталог, радар с режимом «Точки» по умолчанию, матрица «Точки / Ячейки», карточка и инспектор сценария. Сохранены серверные API, PostgreSQL, миграции, импорт и защита beta.

Проверки: `npm ci`, `npm run check` (90 тестов и сборка), 17 интеграционных тестов PostgreSQL, 56 браузерных проверок на 80 сценариях и 6 на 2 500. Использованы отдельные локальные тестовые базы. [CI проверенного SHA](https://github.com/mihajlovfeda3/ctv-platform/actions/runs/41066485079) прошёл.

Ограничения: полный аудит npm сообщил о 16 предупреждениях средней критичности; аудит зависимостей для запуска приложения не выявил уязвимостей. В [инструкции beta](free-beta.md) указана ветка `codex/free-beta`. Настройки живого сервиса Render и состояние Neon не подтверждены. Конфигурация и данные beta при консолидации не затронуты.
