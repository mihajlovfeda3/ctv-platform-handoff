# Статус реализации сценария

Подтверждённые пользовательские статусы: `yes` — «Реализуется» (синий), `no` — «Не реализуется» (оранжевый). Генератор новых демонстрационных сценариев использует только эти значения.

`unknown` остаётся в хранилище и контракте чтения для совместимости и отсутствующих сведений. Миграции и массового изменения данных нет; повторный seed не исправляет старые статусы. ID, связи и оценки сохраняются. Такие записи отображаются с пояснением «Статус требует уточнения», без подтверждённого статуса; точки сохраняют нейтральный серый цвет. В фильтрах и легенде статусов доступны только `yes` и `no`.

Старый параметр `implementation=unknown` в страницах и API игнорируется, как снятый фильтр; остальные условия сохраняются. Переходы строят ссылки без этого параметра. Другие неподдерживаемые значения фильтра остаются ошибкой валидации.

CSV/JSON-импорт принимает явно заданные `yes` и `no`. Явный `unknown`, произвольный текст и другие типы вызывают ошибку и блокируют запись всего импорта. Пустое или отсутствующее значение сохраняется как отсутствие сведений (`unknown`) с предупреждением в диагностике и отчёте импорта. Значения не подменяются на `no`.

Для явной корректировки данных сначала получите перечень записей:

```sql
select id, origin_namespace, external_id, name
from scenarios where implementation = 'unknown'
order by origin_namespace, external_id;
```

Каждый статус следует уточнять по источнику данных; автоматической команды исправления нет.
