# Экспериментальный куб ЦТВ

Маршрут: `/experiments/cube`. Основная навигация, действующий радар, API и схема БД не изменены. Изолированный клиентский компонент использует Three.js и OrbitControls напрямую, без зависимости от версии React. Сервер получает существующий `Analytics` через `scenarioAnalytics`; предел первой итерации — первые 160 записей выборки `SYN-`, восемь направлений из действующей демонстрационной классификации в её исходном порядке.

## Геометрия

Вершины `v` имеют координаты ±1. Каждому направлению принадлежит открытый октант соответствующей вершины. Для РЗ `m` расстояние до вершины равно `r = 0.28 + 0.2(5 − m)`.

В локальной положительной системе вершины строится единичный вектор:

`u = cos(0.25)n + sin(0.25)(cos(θ)e₁ + sin(θ)e₂)`,

где `n=(1,1,1)/√3`, `e₁=(1,−1,0)/√2`, `e₂=(1,1,−2)/√6`, `θ=2π(ОГ−1)/7`. Это ортонормированный базис: ОГ выбирает одну из семи позиций кольца на сферическом слое, не меняя радиуса. ОГ не кодирует ещё одну «зрелость» и не меняет расстояние до вершины.

Итоговая координата по оси: `pᵢ=vᵢ(1−r·uᵢ)`. Все компоненты `u` положительны; при максимальном `r=1.08` они дают смещение менее 1. Поэтому координаты сохраняют знаки вершины и остаются внутри её октанта. Проверяется и запас до границ для максимальной сферы с выделением. Ни ID, ни статус, ни влияние, ни камера в расчёте позиции не участвуют.

Совпадающие сценарии остаются в одной точке: при нажатии доступны все записи в этой позиции. Также доступен список сценариев для выбора с клавиатуры. Случайных смещений и отдельного режима групп нет. Радиусы влияния 1/2/3: 0.025/0.04/0.055; при отсутствии влияния — маленькая сфера 0.018 с явным пояснением в сведениях. Записи без РЗ, ОГ или подтверждённого статуса исключаются из позиционирования, их количество показано отдельно.

## Управление и ограничения

Перетаскивание вращает сцену; колесо и кнопки меняют масштаб. Сброс очищает остаточную инерцию. Выбор направления приглушает другие октанты, фокус переводит камеру к выбранной области. Номер каждой вершины проецируется из её мировой координаты; полные названия находятся в легенде и подсказках без пересекающих центр направляющих. Постоянного вращения нет: кадры запрашиваются при взаимодействии, затухании управления и изменении размера. Настройка reduced motion отключает инерцию.

При отсутствии WebGL2 или потере контекста доступен текстовый список. Прототип не интегрирован с инспектором, не имеет новых фильтров и не предназначен для большого каталога без дополнительной приёмки.

Проверки: `npm run check`; `npm run test:e2e -- tests/browser/cube.spec.ts --project=1440` (сам тест проверяет 1366×768, 1440×900, 1920×1080 и отсутствие WebGL). Геометрия: `npm test -- tests/cube-geometry.test.ts`.
