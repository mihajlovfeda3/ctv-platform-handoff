# Экспериментальный куб ЦТВ

Основной маршрут: `/scenarios/cube`, четвёртое представление раздела «Сценарии». Экспериментальный маршрут `/experiments/cube` сохранён. Действующий радар, API и схема БД не изменены. Изолированный клиентский компонент использует Three.js и OrbitControls напрямую, без зависимости от версии React. Сервер получает существующий `Analytics` через `scenarioAnalytics`; предел первой итерации — первые 160 записей выборки `SYN-`, восемь направлений из действующей демонстрационной классификации в её исходном порядке.

## Геометрия

Вершины `v` имеют координаты ±1. Каждому направлению принадлежит открытый октант соответствующей вершины. Для РЗ `m` расстояние до вершины равно `r = 0.28 + 0.2(5 − m)`.

В локальной положительной системе вершины строится единичный вектор:

`u = cos(0.25)n + sin(0.25)(cos(θ)e₁ + sin(θ)e₂)`,

где `n=(1,1,1)/√3`, `e₁=(1,−1,0)/√2`, `e₂=(1,1,−2)/√6`, `θ=2π(ОГ−1)/7`. Это ортонормированный базис: ОГ выбирает одну из семи позиций кольца на сферическом слое, не меняя радиуса. ОГ не кодирует ещё одну «зрелость» и не меняет расстояние до вершины.

Итоговая координата по оси: `pᵢ=vᵢ(1−r·uᵢ)`. Все компоненты `u` положительны; при максимальном `r=1.08` они дают смещение менее 1. Поэтому координаты сохраняют знаки вершины и остаются внутри её октанта. Проверяется и запас до границ для максимальной сферы с выделением. Ни ID, ни статус, ни влияние, ни камера в расчёте позиции не участвуют.

Совпадающие сценарии остаются в одной точке: при нажатии доступны все записи в этой позиции. Также доступен список сценариев для выбора с клавиатуры. Случайных смещений и отдельного режима групп нет. Радиусы влияния 1/2/3: 0.020/0.028/0.036; при отсутствии влияния — маленькая сфера 0.015 с явным пояснением в сведениях. Записи без РЗ, ОГ или подтверждённого статуса исключаются из позиционирования, их количество показано отдельно.

## Управление и ограничения

Перетаскивание вращает сцену; колесо и кнопки меняют масштаб. Минимальное расстояние до цели — 0.18, near plane — 0.008: камера может заходить внутрь куба, не достигая вырожденного нулевого расстояния. Сброс очищает остаточную инерцию и возвращает исходную камеру. Выбор направления приглушает другие октанты, фокус переводит камеру к выбранной области. Текстовые подписи направлений проецируются из мировых координат вершин. Сокращения сохраняют смысл, полное название доступно в title и правой панели; номера вторичны. Подписи размещаются без пересечений в пределах рабочей области и связаны с вершинами короткими выносками. При предельно плотной проекции приоритет имеет выбранное направление, не помещающиеся подписи скрываются, а все направления остаются доступны справа. Три слабые центральные сетки разделяют объём, небольшая точка отмечает центр. Эти ориентиры не кодируют дополнительные показатели. Постоянного вращения нет: кадры запрашиваются при взаимодействии, затухании управления и изменении размера. Настройка reduced motion отключает инерцию.

При отсутствии WebGL2 или потере контекста доступен текстовый список. Прототип не интегрирован с инспектором, не имеет новых фильтров и не предназначен для большого каталога без дополнительной приёмки.

Проверки: `npm run check`; `npm run test:e2e -- tests/browser/cube.spec.ts --project=1440` (сам тест проверяет 1366×768, 1440×900, 1920×1080 и отсутствие WebGL). Геометрия: `npm test -- tests/cube-geometry.test.ts`.

## Интеграция

Основной маршрут получает текущую выборку через `scenarioAnalytics` с общими URL-фильтрами; ограничение `SYN-` применяется только к старому экспериментальному маршруту. Сохранён предел 160 записей; выбранная запись включается в этот предел, если соответствует фильтрам. Выбор вне фильтра сохраняется в URL с пояснением. Отдельного API и отдельной БД нет.

Общая навигация и сайдбар содержат четвёртую ссылку «3D-куб». Существующие фильтры доступны в свёрнутом блоке. Выбор из 3D, развёртки или списка обновляет `selected` через native History API без пересоздания сцены; переходы переносят фильтры и выбранный ID. Обратные переходы и история синхронизируют выделение. Собственный просмотр куба сохранён, новые карточки/инспекторы не добавлены.

Целевая интеграционная регрессия: `npm run test:e2e -- tests/browser/cube-integration.spec.ts tests/browser/cube.spec.ts --project=1440` (внутри проверяются 1440×900 и 1920×1080, переходы по четырём представлениям, фильтры, выбор, геометрические взаимодействия и отсутствие WebGL).
